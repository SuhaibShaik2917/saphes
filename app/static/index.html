Saphes

AI answers expire. Saphes tells you which parts already did.

Paste an answer, drop a link, or upload a document. Every factual claim is checked against the live web and stamped CURRENT, STALE or UNCERTAIN — with the source we used and the moment we looked. Opinions, predictions and questions get a label instead of a grade.

Demo mode: claims are verified against live web search when the network allows it, with cached evidence and a deterministic fallback if it does not.
